# Bungie Bound — My Notes

## What is it?

Bungie Bound looks at changing careers.

It asks:

**What skills can I bring with me, and what do I still need to learn?**

---

## What does my Python do?

It compares:

**What I already know**

with:

**What the new job wants**

Then it separates them into:

* ✅ Skills I already have
* ⚠️ Skills I still need to learn

---

## Simple Example

**I have:** Teamwork, Problem Solving

**Job wants:** Teamwork, Problem Solving, Wwise, Unreal

Python shows:

**Already have:** Teamwork, Problem Solving

**Need to learn:** Wwise, Unreal

---

## How does it work?

`for` → Check each skill one by one.

`if` → Do I already have this skill?

`else` → If not, it is a skill I need to learn.

`append()` → Add the skill to the correct list.

---

## Why Python?

It makes comparing my skills with job requirements easier.
