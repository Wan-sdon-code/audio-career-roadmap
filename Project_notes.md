# 📝 Python Script Notes

- `print()` → Shows words on the screen.
- `my_skills` → List of skills I already have.
- `job_skills` → List of skills needed for game audio.
- `already_have` → Saves skills that match.
- `need_to_learn` → Saves skills that are missing.
- `for` → Checks each skill one by one.
- `if` → Checks if I already have the skill.
- `append()` → Adds the skill to the correct list.

## 💡 What the Script Does

The program compares my current skills with game audio skills.

It separates them into:

**Already Have:**  
Teamwork, Problem Solving

**Need to Learn:**  
Sound Design, Wwise, Unreal Engine

Then it shows a simple career path:

**Keep what I know → Learn what's missing → Build something → Show what I can do → Apply**

The idea is simple:

> **Changing career does not always mean starting from zero.**
